= Astra API (ACC) kubernetes API 资源端点
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
浏览集群上的 Kubernetes API 资源，查看 Astra Control 支持哪些资源。这些端点是只读的。

Kubernetes API 资源 API 提供对 Kubernetes API 资源的只读访问权限，以过滤 Astra 在给定集群上支持的资源。
