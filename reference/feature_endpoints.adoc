= Astra API (ACC) 功能端点
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
通过读取功能标志检查启用或禁用了哪些 Astra Control 功能。

Feature API 提供对功能标志资源的只读访问权限，以确定在系统中启用或禁用了哪些功能。
