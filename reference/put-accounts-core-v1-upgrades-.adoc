= 修改升级
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-put]#PUT# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/upgrades/{upgrade_id}`#

将整个存储资源替换为提供的 JSON 请求正文，同时保留不可由用户修改的键值。

*副作用*

* 升级会根据所需状态安排或运行。




[[parameters]]
== 参数

[cols="5*"]
|===
| 名称 | Type | 在 | Required | Description 


| account_id | string | path | True  a| 
包含帐户资源的 ID

* 示例：{{.Account}}




| upgrade_id | string | path | True  a| 
要列出的升级集合的 ID

|===


[[request-body]]
== 请求正文

将整个存储资源替换为提供的 JSON 请求正文，同时保留不可由用户修改的键值。

*副作用*

* 升级会根据所需状态安排或运行。


[cols="4*"]
|===
| 名称 | Type | Required | Description 


| type | string | True  a| 
资源的媒体类型。定义的值为：

* "application/astra-upgrade"




| version | string | True  a| 
资源的版本。定义的值为：

* "1.0"
* "1.1"




| id | string | False  a| 
资源的全局唯一标识符。定义的值为：

* 符合 UUIDv4 架构




| componentName | string | False  a| 
包含可以升级的软件类型名称的 JSON 字符串。定义的值是：

* "acc"
* "acs"
* “trident”
* “kubernetes”




| componentInstance | string | False  a| 
包含可升级的组件 URI 的 JSON 字符串。定义的值为：

* 最小长度：3
* 最大长度：4095




| 组件 ID | string | False  a| 
包含可升级的组件的全局唯一标识符的 JSON 字符串。定义的值为：

* 符合 Astra 标识符架构




| upgradeVersion | string | False  a| 
包含可升级到的软件映像文件的 SemVer 的 JSON 字符串。定义的值为：

* 符合 SemVer 架构




| currentVersion | string | False  a| 
包含要升级的实体当前 SemVer 的 JSON 字符串。定义的值为：

* 符合 SemVer 架构




| 依赖项 | 数组[string] | False  a| 
JSON 字符串的 JSON 数组，每个字符串都包含在此升级继续之前必须完成的升级的 UUID。用于确定哪些升级将作为先决条件执行以及执行顺序。定义的值为：

* 符合 Astra 标识符架构




| 状态 | string | False  a| 
包含指示升级操作状态的值的 JSON 字符串。如果启用自动升级，升级将以"scheduled"状态启动。否则，升级将从"proposed"状态开始。定义的值为：

* "unavailable" - 升级目前不可用
* "proposed" - 已提议升级，但在获得批准之前不会自动运行
* "scheduled" - 升级已获批准，但由于依赖关系、时间窗口或可用资源，尚未准备好安装
* "running" - 正在进行升级
* "complete" - 升级已完成
* "failed" - 升级未完成




| stateDesired | string | False  a| 
包含指示"state"所需状态的值的 JSON 字符串。仅当用户可以直接请求更改资源的状态时，才会包含此字段。定义的值是：

* "proposed" - 升级未获批准，不得执行
* "scheduled" - 升级已获批准，必须在指定时间段内执行
* "running" - 无论时间窗口如何，必须立即执行升级




| stateDetails | 数组[link:#type_astra_stateDetail["type_astra_stateDetail"]] | False  a| 
JSON 对象的 JSON 数组，列出有关当前"状态"的其他详细信息。如果没有可用的详细信息，此数组将为空。

* 最小项目数：0




| 元数据 | link:#type_astra_metadata_update["type_astra_metadata_update"] | False  a| 
与资源关联的客户端和服务指定的元数据。定义的值为：

* 符合 Astra 元数据架构如果在更新时未指定，则元数据对象的标签、creationTimestamp 和 createdBy 将不加修改地保留。


|===
.请求示例
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-upgrade",
  "version": "1.1",
  "stateDesired": "running"
}
----
====
