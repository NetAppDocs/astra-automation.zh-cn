= 创建新证书
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-post]#POST# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/certificates`#

指示要创建的 Certificate API 资源的所需值。



[[parameters]]
== 参数

[cols="5*"]
|===
| 名称 | Type | 在 | Required | Description 


| account_id | string | path | True  a| 
包含帐户资源的 ID

* 示例：{{.Account}}


|===


[[request-body]]
== 请求正文

指示要创建的 Certificate API 资源的所需值。

[cols="4*"]
|===
| 名称 | Type | Required | Description 


| type | string | True  a| 
资源的媒体类型。定义的值为：

* "application/astra-certificate"




| version | string | True  a| 
资源的版本。定义的值为：

* "1.0"
* "1.1"




| certUse | string | False  a| 
表示证书使用情况的 JSON 字符串。如果未指定，则默认为"rootCA"。定义的值为：

* "rootCA" - 证书是证书颁发机构 (CA) 证书，用于信任由该 CA 签名的任何证书。
* "intermediateCA" - 证书是由根 CA 颁发的中间 CA 证书。




| cert | string | True  a| 
包含 base64 编码的 PKCS-11 格式证书 (PEM) 的 JSON 字符串。定义的值是：

* 符合 base64 编码数据架构




| isSelfSigned | string | False  a| 
表示证书是否为自签名的 JSON 字符串。如果在创建时未提供，则该值默认为"false"。更新时：

* 如果提供了值，则将使用该值。
* 如果不提供该值，并且更新中包含 "cert" 字段，则该值将设置为 "false"。
* 如果未提供该值，并且"cert"字段未包含在更新中，则将保留现有值。定义的值为：
* "true" - 证书是自签名的。
* "false" - 此证书不是自签名的。




| trustStateDesired | string | False  a| 
包含指示证书是否受信任的值的 JSON 字符串。如果在创建时未指定，则默认值为"trusted"。定义的值为：

* "untrusted" - 此证书不受信任。
* "trusted" - 证书被标记为可信。




| 元数据 | link:#type_astra_metadata_update["type_astra_metadata_update"] | False  a| 
与资源关联的客户端和服务指定的元数据。定义的值为：

* 符合 Astra 元数据架构如果在创建时未指定，则将创建没有标签的元数据对象。如果在更新时未指定，则元数据对象的标签、creationTimestamp 和 createdBy 将保留而不进行修改。


|===
.请求示例
[%collapsible]
====
[source, json, subs="+macros"]
----
{
  "type": "application/astra-certificate",
  "version": "1.1",
  "certUse": "rootCA",
  "cert": "LS0tLS1CRUdJTiBDRVJUSUZJQ0FURS0tLS0tCk1JSUZyVENDQTVXZ0F3MVJHbnFGbUJSSWRyV1kwPQotLS0tLUVORCBDRVJUSUZJQ0FURS0tLS0t"
}
----
====


[[response]]
== 响应

[source]
----
Status: 201, Returns the newly created certificate resource in the JSON response body.
----
[cols="4*"]
|===
| 名称 | Type | Required | Description 


| type | string | True  a| 
资源的媒体类型。定义的值为：

* "application/astra-certificate"




| version | string | True  a| 
资源的版本。定义的值为：

* "1.0"
* "1.1"




| id | string | True  a| 
资源的全局唯一标识符。定义的值为：

* 符合 UUIDv4 架构




| certUse | string | True  a| 
表示证书使用情况的 JSON 字符串。如果未指定，则默认为"rootCA"。定义的值为：

* "rootCA" - 证书是证书颁发机构 (CA) 证书，用于信任由该 CA 签名的任何证书。
* "intermediateCA" - 证书是由根 CA 颁发的中间 CA 证书。




| cert | string | True  a| 
包含 base64 编码的 PKCS-11 格式证书 (PEM) 的 JSON 字符串。定义的值是：

* 符合 base64 编码数据架构




| cn | string | True  a| 
包含从证书中提取的通用名称的 JSON 字符串。定义的值是：

* 最小长度：1
* 最大长度：511




| expiryTimestamp | string | True  a| 
包含指示证书何时过期的时间戳的 JSON 字符串。定义的值为：

* 符合 ISO-8601 日期时间方案




| isSelfSigned | string | True  a| 
表示证书是否为自签名的 JSON 字符串。如果在创建时未提供，则该值默认为"false"。更新时：

* 如果提供了值，则将使用该值。
* 如果不提供该值，并且更新中包含 "cert" 字段，则该值将设置为 "false"。
* 如果未提供该值，并且"cert"字段未包含在更新中，则将保留现有值。定义的值为：
* "true" - 证书是自签名的。
* "false" - 此证书不是自签名的。




| trustState | string | True  a| 
包含指示证书是否受信任的一组枚举值之一的 JSON 字符串。定义的值为：

* "untrusted" - 此证书不受信任。
* "trusted" - 证书被标记为可信。
* "expired" - 证书已过期，因此既不受信任也不不受信任。




| trustStateTransitions | 数组[link:#type_astra_stateTransition["type_astra_stateTransition"]] | True  a| 
JSON 对象的 JSON 数组，每个表示从给定定义状态的允许状态转换集。每个 JSON 对象都包含"from"和"to"字段，其中"from"值是状态的名称，"to"值是允许的目标状态数组。



| trustStateDesired | string | False  a| 
包含指示证书是否受信任的值的 JSON 字符串。如果在创建时未指定，则默认值为"trusted"。定义的值为：

* "untrusted" - 此证书不受信任。
* "trusted" - 证书被标记为可信。




| trustStateDetails | 数组[link:#type_astra_stateDetail["type_astra_stateDetail"]] | True  a| 
列出有关证书信任状态的其他详细信息的 JSON 对象的 JSON 数组。如果没有可用的详细信息，则此数组将为空。

* 最小项目数：0




| 元数据 | link:#type_astra_metadata_update["type_astra_metadata_update"] | True  a| 
与资源关联的客户端和服务指定的元数据。定义的值为：

* 符合 Astra 元数据架构如果在创建时未指定，则将创建没有标签的元数据对象。如果在更新时未指定，则元数据对象的标签、creationTimestamp 和 createdBy 将保留而不进行修改。


|===
.响应示例

  "type": "application/astra-certificate",
  "version": "1.1",
  "id": "a26cbed4-2183-58ce-aa19-e37ca8b0531a",

  "cert": "LS0tLS1CRUdJTiBDRVJUSUZJQ0FURS0tLS0tCk1JSUZyVENDQTVXZ0F3MVJHbnFGbUJSSWRyV1kwPQotLS0tLUVORCBDRVJUSUZJQ0FURS0tLS0t",
  "cn": "vcenter.example.com",
  "isSelfSigned": "false",
  "expiryTimestamp": "2022-03-23T16:48:38.5233461Z",

    "labels": [],
    "creationTimestamp": "2022-10-06T20:58:16.305662Z",
    "modificationTimestamp": "2022-10-06T20:58:16.305662Z",

  }
}
----
