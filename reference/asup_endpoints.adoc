= Astra API (ACC) ASUP 端点
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
创建 AutoSupport（ASUP）捆绑包，并可选择将其上传至 NetApp，以帮助排除故障。

ASUP API 提供对 ASUP 资源的访问权限，以便创建和上传 AutoSupport 捆绑包（可选）。
