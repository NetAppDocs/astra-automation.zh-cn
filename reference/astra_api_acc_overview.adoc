= Astra API (ACC) 概述
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
查找自动化 Astra Control 任务所需的端点、HTTP 方法、输入参数和响应。API 为您提供对 Astra Control 资源的创建、读取、更新和删除访问权限。

Astra Control REST API 参考文档包含所有 REST API 调用的详细信息，包括端点、HTTP 方法、输入参数和响应。在使用 API 开发自动化应用程序时，此完整参考非常有用。Astra REST API 提供对所有 Astra Control 资源的 CRUD（Create-Read-Update-Delete）访问，特定资源类别除外。本参考文档适用于 Astra Control REST API 的 24.02 版本。
