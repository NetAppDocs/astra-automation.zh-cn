= Astra API (ACC) 未读通知端点
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
查找用户尚未阅读的通知，并将其标记为已读。

Unread Notification API 提供有关未被给定用户读取的通知的信息，并允许将其标记为已读。
