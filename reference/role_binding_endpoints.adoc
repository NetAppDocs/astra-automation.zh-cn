= Astra API (ACC) 角色绑定端点
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
管理向帐户中的用户或组授予权限的角色绑定。角色绑定会将用户或组链接到一个角色。

Role Binding API 描述了用户账户对或组账户对之间的关系，以及它们被授予的权限集（角色）。
